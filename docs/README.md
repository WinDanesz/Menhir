# Menhir Mod Wiki

This directory contains the documentation and wiki for the **Menhir Mod**, a Minecraft mod that adds custom birthsigns and abilities. 

The live wiki is available at: [https://windanesz.github.io/Menhir](https://windanesz.github.io/Menhir)

## Local Development

The wiki is built using [Docusaurus](https://docusaurus.io/). To run it locally:

```bash
# Install dependencies
yarn

# Start the local development server
yarn start
```

## Build

```bash
yarn build
```

This command generates static content into the `build` directory and can be served using any static contents hosting service.
