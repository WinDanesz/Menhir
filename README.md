# Menhir Mod

https://www.curseforge.com/minecraft/mc-mods/menhir

Menhir is a Minecraft mod that adds custom birthsigns, abilities, and mechanics to the game.

## Features

- **Birthsigns:** Choose from various birthsigns that grant unique active and passive abilities.
- **Custom Abilities:** An extensible system for granting abilities to players, such as the Archer's arrow salvage, the Lodestone's mark and recall, and more!
